# Weather Station Dashboard 🌦️

Ένα custom dashboard για την παρακολούθηση μετεωρολογικών δεδομένων σε πραγματικό χρόνο.

## Χαρακτηριστικά
* **Δυναμικά Widgets:** Πυξίδα ανέμου, ταχύμετρο, σταγόνα υγρασίας και θερμόμετρο εδάφους.
* **Smart Colors:** Τα εικονίδια αλλάζουν χρώμα ανάλογα με τις τιμές (π.χ. κόκκινο για καύσωνα, μπλε για κρύο).
* **Dark/Light Mode:** Πλήρης υποστήριξη θέματος ανάλογα με τις προτιμήσεις του χρήστη.
* **24h Format:** Όλες οι ενδείξεις ώρας ακολουθούν το ευρωπαϊκό πρότυπο.

## Τεχνολογίες
* Python (Flask)
* JavaScript (ES6)
* CSS3 & SVG Animations
* MySQL
